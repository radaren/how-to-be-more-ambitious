# How to be more ambitious — 中英逐行互译

Mobile-friendly, line-by-line Chinese–English bilingual reading of Felix Rieseberg’s essay **How to be more ambitious: A tutorial for humans with models**.

移动端优先的逐句中英互译阅读页（非官方翻译）。

## Live site / 在线阅读

**https://radaren.github.io/how-to-be-more-ambitious/**

## Original / 原文

- Author: [Felix Rieseberg](https://felixrieseberg.com/)
- Essay: https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/

## Features

- EN then CN stacked per sentence / heading / list item / blockquote（宽屏可选左右对照）
- Toggle: 双语 / EN / 中文
- GitHub Pages static site (`index.html` + CSS/JS at repo root)

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
